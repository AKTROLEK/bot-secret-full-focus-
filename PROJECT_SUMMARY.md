## 🚀 How to Get Started

### Quick Start (30 minutes)
```bash
# 1. Clone repository
git clone https://github.com/AKTROLEK/bot-secret-full-focus-.git
cd bot-secret-full-focus-

# 2. Install dependencies
npm install

# 3. Configure environment
cp .env.example .env
# Edit .env with your values

# 4. Build and run
npm run build
npm start

# 5. Deploy dashboard
cd dashboard
vercel deploy
```
